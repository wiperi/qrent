# Visible guide topics and search

The experience-post index keeps its existing bilingual content and blue/white
layout. Show every topic as a wrapping, single-choice button, including All topics
and article counts. Put a labeled text search alongside the topics; it searches
titles, summaries and topic labels, and combines with the selected topic. Provide
result counts and a clear-filters action for empty results. Keep the rental
progress panel and existing handbook entry.

These are in-page controls, not new indexable category pages. Every published
article retains its existing URL, server-rendered title/link, sitemap entry and
reciprocal language link. Audit the public initial HTML, canonical/hreflang,
robots, sitemap and internal article reachability. This does not establish Google
indexing or ranking, which requires Search Console evidence.

Verify filtering with multilingual/case/whitespace inputs and combined conditions;
verify initial HTML contains all paired article links and visible topics. Build,
inspect desktop/mobile and both languages in one bounded pass, then release
through the original GitHub PR/integration path. No crawler, schema or paid
provider changes are needed.
